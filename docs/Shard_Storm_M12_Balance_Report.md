# M12 — policy A/B and scheduler balance checkpoint

650개의 실제 전투를 실행했습니다. 기준 M11 commit은 `633f8a4`입니다. [원본 결과](../artifacts/m12-benchmark-results.json), [실행 로그](../artifacts/m12-benchmark.txt). 자동 입력은 같은 시드/정책이며 인간의 재미·조준 정확도·플레이 시간을 뜻하지 않습니다. 이 문서는 M12 운영 선택 전 checkpoint입니다.

## Scheduler

5seed(31415/1/7/42/99)×3build(Crusher/Cascade/Reactor)×Rank0/4×20/32초×Normal/unstableCore=120조건, M11 원본/M12 OFF/M12 ON 각각 실행해360전투입니다. Rank0은Fresh0레벨, Rank4는MAX49+빌드 Signature/Evolution fixture입니다. M12 OFF와 M11 원본은120조건 모두 파괴/Raw/Photon/Catalyst/스킬/도형 통계/Codex/Elite/인과 target 열이 정확히 동일했습니다. 이120조건에는 원래 cap 경로가 없었고 ON 역시 모두 동일했습니다.

추가 seed2..6×20/32초를 loadout 없이 원본/수정 각각 실행해20전투입니다. seed2에서 원본은29회의 tick cap을 만났지만 수정은1회의 budget yield 후 잔여9.52381ms를 처리했습니다. 폐기 시간은0입니다.20초 파괴305→308,Raw9887→9749;32초484→489,Raw17086→16921입니다. 더 많은 파괴에도 보상은 자동 증가하지 않으며 수정된 인과 경로/등장 구성에 따라 바뀝니다. 나머지8조건은 정확히 동일했습니다. caps를 올리거나 새 피해를 지급한 결과가 아닙니다.

별도 단위 시험1,000 fixture×600사건은650전투 수에 포함하지 않습니다. 파편 실제 이동/사건 순서/지급 중복0/late contact0/폐기0을 검증합니다. visible stall의 기존 skip 정책은 별개입니다.

## Elite 후보

소개가 완료된MAX fixture에서 같은5seed×3build로 정책당15회,6정책90전투입니다. M11 attempt3%는14/15, Run3/15%는 각각3/15, Run20/25% 및20%+pity6는 각각6/15회 등장했습니다. 작은 표본이며 동일 시드의 상관이 있으므로 이 비율을 실제 모집단 등장률로 해석하지 않습니다. 실제 배치 실패0이며 Run 최대1회/기존 보상 규칙을 유지했습니다.

별도로 후보당10,000개의 적격Run 추첨을 실행하고, Run마다100회 호출해도 다시 추첨하지 않음을 확인했습니다. **50,000회 추첨 실험이며50,000회의20초 전투가 아닙니다.** 당첨 시 안전 배치가 가능하다고 놓은 비교이고, 실제 실패/소개 처리는 전투와 음성fixture에서 별도로 확인했습니다.

권장은 **Run20%+pity6**입니다. M11의 적격attempt 누적으로 거의 매Run 등장하는 문제를 줄이면서 지나치게 긴 미등장을 막습니다. 최초 소개는 별도이며, 보장은 등장 자체가 아닌 안전 배치 시도입니다. 실패하면 pity를 보존합니다. 이 권장은 사람의 희귀도 선호가 확정됐다는 뜻이 아닙니다. PRD에서 미확정으로 둔 운영 정책이며 보상 기회/영속pity 변경을 수반하므로 사용자 결정 전에는live에 적용하지 않았습니다.

확률3% 자체를 우선하면 Run3%/pity없음도 구현된 후보지만, 실험에서 긴 미등장이 관측됐습니다. 채택 후 schema9가 필요한 정책은 exactly-once 정산과 마이그레이션을 추가 검증합니다.

## 미검증

공급/Elite 변경 후50/100/200/300Run 자연 성장은 아직 실행하지 않았습니다. 현재는 운영 선택 전의 개별Run 비교이며 M11의 과거54,000Run을 M12 완료 근거로 전용하지 않습니다. M13 거리/연결 군집, M14 캠페인, M15 선택형 모드, M16 음향/엔딩은 다음 단계로 아직 구현하지 않았습니다. 사람의 신선함/가독성/재도전 이유/3~4시간 목표도 미검증입니다.
