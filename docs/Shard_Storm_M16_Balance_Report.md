# M16 — 성장·성능·경제

M16의 변경은 표현과 접근성이다. 기존 가격·HP·환전율·자산을 일괄 조정하지 않았다. 1,350회 M15/ON/OFF 비교에서 실제 전투·정산 결과는 일치했다.

## 장기 캠페인 실험

고정 M15 런타임 `2f71f4c`를 별도 임시 디렉터리에 고정하여 실행했다. 5시드×Crusher/Cascade/Reactor, 실제 구매 가능할 때만 강화, 실제 Survey·보스 조건에 따라 가장 높은 적격 월드로 이동했다. Research나 선택형 모드를 강제하지 않았다. M16과의 전투 동등성은 별도450조건에서 검증했다.

첫 코호트는4500 Run, 각 경로300회다. 보조 함수의 duration 기본값 때문에 구매 Extra Time과 무관하게 실제20초로 실행된 것을 기록에서 확인했다. 이를 **Fixed20 코호트**로 명시하고 결과·체크포인트를 보존했다. Extra Time을 반영한 별도750 Run(5시드×3전략×50회)을 추가하여 실제20/22/24/26/28/30/32초를 확인했다. 두 코호트를 합산하여 같은 시간 정책인 것처럼 보고하지 않는다.

Fixed20의 전략별5시드 중앙값:

| Run | 구매 레벨 범위 /100 | Photon 잔고 범위 | 이번 Run 파괴 범위 | 캠페인 완료 |
|---|---:|---:|---:|---:|
|5|8~9|17~63|225~283|0/15|
|20|31~34|62~90|294~297|0/15|
|50|67~69|57~126|302|15/15|
|100|99~100|919~1880|311~316|15/15|
|200|100|47162~52427|308~314|15/15|
|300|100|123396~131672|304~307|15/15|

Fixed20의 실제 최초 캠페인 완료는 경로별 Run32~43, Extra Time 코호트에서는 Run28~34다. 이는 전술을 아는 자동 입력·자동 구매의 결과이며 사람의 시간·성공률·재미가 아니다. Extra Time Run50 중앙값은 레벨79~84, Photon66~213, 파괴508~519로 Fixed20과 차이가 있다.

가장 큰 미해결 밸런스 문제는 Run100 부근의 스킬 완성 후 Run300에12만~13만 Photon이 쌓이는 점이다. 또한 M15의 대부분 Research는 일반 Run의 평균 수익을 낮추어 가격 대비 상황적 가치가 약할 수 있다. 가격 인상·세이브 초기화로 이를 감추지 않았다. 인간의 선택·목표 소진·보스 난도 데이터를 먼저 수집해야 한다.

## 성능

450조건에서 CPU update p95의 중앙값: M15 0.5231ms / M16 ON 0.5113ms / OFF 0.5070ms. ON의 조건별 최대 p95는0.9012ms다. 동시 실행·기기 영향을 받는 표본이며 GPU 렌더 시간이나 화면 FPS와 다르다.

Chrome 실제6개 World 표본의 RAF 기반 평균 FPS는 약130~131, 입력 전달 p95는0.6~1.1ms, 최대 voice는6~7/8이었다. headless Chrome155 환경의 관측값이며 다른 장치의 FPS나 실제 소리 도달 지연을 보장하지 않는다. 파편150·파동64·이벤트1024 안전 상한은 유지했다.
