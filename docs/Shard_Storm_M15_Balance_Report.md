# M15 — 경제·선택형 성장 비교

5시드31415/1/7/42/99, 3빌드, 명시적인 Rank4/MAX fixture. 자동 전투 결과이며 자연 계정의 완료 시간이나 사람의 재미를 뜻하지 않는다.

## 경제 정책

기존 스킬 가격·환전율·재화는 변경하지 않았다. Draft는5 Run 전체 영구 Photon/Catalyst0이다. Protocol·Depth는 별도 반복 통화 보너스 없이 뱃지와 기존 보상만 제공한다.

Research 신규 가격은 PRD 후보 범위 안에서 2000/4000/6000/8000/10000/12000 Photon, 20/40/60/80/100/150 Catalyst로 분산했다. 합계42000 Photon·450 Catalyst다. 기존 M13의 실제3000 Run 성장 코호트에서 Run50의 잔고로 전부 즉시 구매할 수 없고, Run100에도 대부분 부족하며 Run200의13만~15만 잉여에서는 구매 가능하다. 이 분석은 **역사적 M13 코호트**이며 M15의 새로운3000 Run 실험이라고 보고하지 않는다. 설계도 해금이 별도 조건이다. 기존 가격 일괄 인상은 하지 않았다.

## 선택형 모드

Depth1/2/3 각75조건의 코어 실제 파괴를 확인했다. Depth2/3의150조건은 실제 혼합 포켓 배치 보강 뒤 재검증했다. MAX의 쉬운 과거 보스 재방문을 막지 않는다.

Draft 5 Run 합산 점수 범위: Crusher2359~2788, Cascade2565~3526, Reactor2694~3436. 동일 seed·동일 선택의 완주2회 점수가 일치했다. 점수는 파괴1 + 최고Chain×5 + 최대거리px + 실제 고유메커니즘×20 + Chain Salvage100으로 선언하며 화폐로 변환하지 않는다.

현재 가장 큰 위험은 장기 재화 잉여 자체와 함께, 선택형 Research의 비용 대비 상황적 이득이 약할 수 있다는 점이다. 사람 코호트에서 구매 포기·활성 유지·재도전 선택을 수집해야 한다.
