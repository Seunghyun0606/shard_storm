# M12 Elite 운영 정책 결정 지점

상태: **결정 전**. 비교 가능한 후보의 실제 구현/단위 테스트/전투 실험/브라우저 QA를 먼저 수행했습니다. M12 PRD §5에서 `기본 검토 후보 .20+pity, 확정 아님`, `운영안은 ... 사람 테스트 ... 확인 후 채택`이라고 남긴 선택입니다. 사용자의 Remote Control Human Gate 규칙에 따라 보상 기회와 영속 필드가 바뀌는 운영 전환은 아직 수행하지 않았습니다.

공통: Account Rank/insight/Run Tier4 자격, 소개 우선권 별도, 최대1Elite/Run, 안전한 전체 구조물 배치, native Raw+50/Catalyst+3 보상1회. 공급은 현재 fixed15를 유지하므로 이 결정과 함께 공급량까지 바꾸지 않습니다.

|안|운영 규칙|10,000 적격Run 추첨의 당첨|최대 연속 미당첨|저장 변경|
|---|---|---:|---:|---|
|A · 권장|적격Run당20%,6회 연속 자연 미등장 후 다음 적격Run 생성 시도 보장|2506(25.06%)|6|schema9에pity 추가, 기존 데이터 보존/정산1회로만 갱신|
|B|적격Run당3%,보장 없음|319(3.19%)|172|pity 필드 불필요|

위 수치는 추첨 실험입니다. 실제 전투6정책×15회에서는 M11 attempt3%가14/15회, Run3%가3/15회, Run20%+pity6가6/15회 생성됐으나 작은 동일시드 표본을 장기 출현률로 해석하지 않습니다. 전체 M12 실전650회와50,000 추첨은 [Balance Report](Shard_Storm_M12_Balance_Report.md)에 분리 기록했습니다.

A의 보장은 안전 배치 시도이며 강제 중첩 생성이 아닙니다. 실제 자연 생성 성공에만 pity가0으로 돌아가고 배치 실패는 보장 상태를 보존합니다. 소개/강제fixture는 자연 미등장 횟수를 소비하지 않습니다. 기존 단위 테스트와 격리 개발자 비교에서 이 규칙을 검증했습니다.

어느 안도 기존 Photon/Catalyst/스킬/20전체기록을 삭제하거나 기존 보상을 소급 재계산하지 않습니다. 결정 후 운영 연결/필요한 migration과 장기 성장을 검증하고 M12 최종 완료→M13~M16 순서로 계속 개발합니다. 이는 M12~M16 전체 완료 보고가 아닙니다.
