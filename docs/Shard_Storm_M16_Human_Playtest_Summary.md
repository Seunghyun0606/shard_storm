# M16 — 사람 플레이 검증 상태

참여자 코호트: **미실시**. 이번 결과는 자동 입력·실제 Chrome 포인터 자동화·단위·저장·렌더 검증이다. 사람의 재미, 3~4시간 목표 달성, 멀미·광과민성 안전성을 완료 처리하지 않는다.

다음 실제 플레이에서 기록할 항목:

1. Fresh 시작부터 World5까지 실제 플레이 시간, Run 수, 업그레이드·결과 화면 체류 시간과 이탈 시점.
2. 한 번의 클릭이 만드는 연쇄 거리·군집·화면 반응을 초반/후반에 다르게 느끼는지.
3. World2 Rank1 Normal과 Rank2 Boss의 차이, Survey의 필요 조건과 마지막 실패 이유를 이해하는지.
4. Boss5개 각각 첫 타깃·보호 해제·Mirror 경로·Phase 취약 창·Storm Heart 연결을 스스로 선택할 수 있는지. 실패·재시도 횟수와 포기 이유.
5. 다음 Run을 선택한 이유, 스킬 완성 뒤 재화의 의미, Research를 구입·장착·해제하는 이유와 비용 만족도.
6. Protocol/Depth/Draft의 선택성을 이해하는지, Draft5 Run과 임시 선택이 서로 다른 빌드를 만드는지.
7. 음량·Comfort·Reduced Motion·Focus의 발견 가능성, 눈부심·반복음·멀미·피로, 키보드 조작과 좁은 화면의 가독성.
8. 엔딩 Skip/Replay/Free Play의 선택과 엔딩 이후에도 이어서 플레이할 동기가 있는지.

결과는 중앙값·분산과 함께 기록하고 자동 입력 결과와 분리한다. 실제 기록을 얻기 전 가격 일괄 인상·보유 스킬 초기화·고비용 VFX 확대를 밸런스 해법으로 채택하지 않는다.
